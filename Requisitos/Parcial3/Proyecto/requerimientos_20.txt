REQUISITOS FUNCIONALES - SIMULADOR DE INVERSIONES EN CRIPTOMONEDAS
Formato IEEE 830 - 20 Requisitos Funcionales
==================================================================

REQUISITOS FUNCIONALES EXISTENTES (RF01 - RF10)
==================================================================

RF01: El sistema debe permitir al usuario registrarse con nombre,
      correo electrónico y contraseña, e iniciar sesión para acceder
      a la aplicación.
      - Tipo: Obligatorio
      - Prioridad: Alta
      - Pantalla: Login/Registro

RF02: El sistema debe mostrar el precio actual de cada criptomoneda
      disponible en el mercado, incluyendo su variación porcentual
      respecto al periodo anterior.
      - Tipo: Obligatorio
      - Prioridad: Alta
      - Pantalla: ScrInicio (Dashboard) y ScrMercado

RF03: El sistema debe permitir al usuario simular la compra de
      criptomonedas ingresando la cantidad deseada, calculando el
      total estimado según el precio actual y descontándolo del
      saldo virtual disponible.
      - Tipo: Obligatorio
      - Prioridad: Alta
      - Pantalla: ScrDetalle

RF04: El sistema debe permitir al usuario simular la venta de
      criptomonedas que posee en su portafolio, validando la
      cantidad disponible y acreditando el monto al saldo virtual.
      - Tipo: Obligatorio
      - Prioridad: Alta
      - Pantalla: ScrDetalle

RF05: El sistema debe calcular y mostrar las ganancias o pérdidas
      totales del portafolio del usuario, comparando el valor actual
      de sus activos contra el costo de adquisición.
      - Tipo: Obligatorio
      - Prioridad: Alta
      - Pantalla: ScrInicio (Dashboard) y ScrPortafolio

RF06: El sistema debe registrar y mostrar el historial completo de
      transacciones del usuario, incluyendo tipo (compra/venta),
      criptomoneda, cantidad, precio unitario, total y fecha.
      - Tipo: Obligatorio
      - Prioridad: Alta
      - Pantalla: ScrHistorial

RF07: El sistema debe validar que el usuario disponga de saldo
      virtual suficiente antes de confirmar una operación de compra.
      En caso contrario, debe mostrar un mensaje de error.
      - Tipo: Obligatorio
      - Prioridad: Alta
      - Pantalla: ScrDetalle

RF08: El sistema debe validar que el usuario posea la cantidad
      suficiente de una criptomoneda antes de confirmar una operación
      de venta. En caso contrario, debe mostrar un mensaje de error.
      - Tipo: Obligatorio
      - Prioridad: Alta
      - Pantalla: ScrDetalle

RF09: El sistema debe mostrar un gráfico circular (pie chart) con la
      distribución porcentual de las criptomonedas en el portafolio
      del usuario.
      - Tipo: Obligatorio
      - Prioridad: Media
      - Pantalla: ScrPortafolio

RF10: El sistema debe permitir al usuario buscar y filtrar
      criptomonedas en el mercado por nombre o símbolo, actualizando
      la lista en tiempo real según el criterio ingresado.
      - Tipo: Obligatorio
      - Prioridad: Media
      - Pantalla: ScrMercado

REQUISITOS FUNCIONALES NUEVOS (RF11 - RF20)
==================================================================

RF11: El sistema debe incluir un apartado de conversión de
      criptomonedas que permita al usuario seleccionar una moneda
      de origen y una moneda de destino (o viceversa), mostrando
      el monto equivalente según el precio actual de cada una.
      - Tipo: Obligatorio
      - Prioridad: Media
      - Pantalla: ScrMercado o ScrDetalle

RF12: El sistema debe permitir al usuario configurar la moneda base
      de visualización (USD, EUR, etc.) para que todos los valores
      monetarios se muestren en la divisa seleccionada.
      - Tipo: Obligatorio
      - Prioridad: Baja
      - Pantalla: Configuración de cuenta

RF13: El sistema debe mostrar la información de precios de cada
      criptomoneda seleccionada, incluyendo precio actual, variación
      porcentual y descripción, sin incluir gráfico de tendencia.
      - Tipo: Obligatorio
      - Prioridad: Media
      - Pantalla: ScrDetalle

RF14: El sistema debe mostrar información descriptiva de cada
      criptomoneda, incluyendo nombre completo, símbolo, precio
      actual, variación porcentual y una breve descripción de su
      propósito o tecnología.
      - Tipo: Obligatorio
      - Prioridad: Media
      - Pantalla: ScrDetalle

RF15: El sistema debe registrar automáticamente el saldo inicial
      virtual de $10,000.00 USD al momento del registro de un
      nuevo usuario, el cual podrá utilizar para simular
      inversiones.
      - Tipo: Obligatorio
      - Prioridad: Alta
      - Pantalla: Registro (automático)

RF16: El sistema debe mostrar una notificación de confirmación
      exitosa al usuario después de cada transacción realizada
      (compra o venta), mostrando el resumen de la operación
      ejecutada.
      - Tipo: Obligatorio
      - Prioridad: Media
      - Pantalla: ScrDetalle (post-transacción)

RF17: El sistema debe permitir al usuario cerrar sesión (logout)
      de forma manual, limpiando las variables de sesión y
      redirigiendo a la pantalla de login.
      - Tipo: Obligatorio
      - Prioridad: Alta
      - Pantalla: Configuración / Botón de cerrar sesión

RF18: El sistema debe persistir los datos del portafolio, saldo
      y historial de transacciones del usuario entre sesiones,
      utilizando Dataverse (o la fuente de datos seleccionada)
      como almacenamiento persistente.
      - Tipo: Obligatorio
      - Prioridad: Alta
      - Backend: Dataverse / SharePoint

RF19: El sistema debe mostrar en el Dashboard (ScrInicio) un
      resumen consolidado del portafolio del usuario, incluyendo:
      valor total del portafolio, ganancia/pérdida del día
      (amount y porcentaje), y saldo disponible en efectivo virtual.
      - Tipo: Obligatorio
      - Prioridad: Alta
      - Pantalla: ScrInicio (Dashboard)

RF20: El sistema debe mantener la sesión del usuario de forma
      persistente, de modo que al cerrar y volver a abrir la
      aplicación, el usuario continúe autenticado sin necesidad
      de ingresar sus credenciales nuevamente.
      - Tipo: Obligatorio
      - Prioridad: Media
      - Pantalla: Login / Configuración
